# Prompt: Comparing Naïve and Basic Prompts Using ChatGPT

## Objective

Conduct an experiment to test and compare how ChatGPT responds to **naïve (broad or unstructured) prompts** versus **basic (clear, detailed, and structured) prompts** across multiple scenarios.

Evaluate the generated responses based on:

* **Quality**
* **Accuracy**
* **Depth**
* **Relevance**
* **Clarity**

## Task Instructions

### Step 1: Select Test Scenarios

Choose at least **5 different scenarios** representing different types of tasks:

1. Creative story generation
2. Factual question answering
3. Article or concept summarization
4. Advice or recommendations
5. Any additional useful scenario, such as problem-solving, explanation, or content generation

### Step 2: Create Two Prompts for Each Scenario

For every scenario, create:

**A. Naïve Prompt:**
Write a broad, simple, or unstructured prompt with minimal instructions and context.

**B. Basic Prompt:**
Create a refined, clear, detailed, and structured prompt that provides specific instructions, context, constraints, expected format, and desired level of detail.

Both prompts must target the **same task**, but the basic prompt should provide significantly more guidance.

### Step 3: Run the Experiment

Use ChatGPT or another AI tool to test both prompts.

For each scenario:

1. Enter the naïve prompt.
2. Record the complete AI-generated response.
3. Enter the corresponding basic prompt.
4. Record the complete AI-generated response.
5. Keep the AI model and other settings the same wherever possible.

### Step 4: Evaluate the Responses

Compare the naïve and basic prompt responses using the following criteria:

| Evaluation Criteria | What to Check                                                            |
| ------------------- | ------------------------------------------------------------------------ |
| Quality             | How well-written, useful, and well-organized is the response?            |
| Accuracy            | Is the information correct and factually reliable?                       |
| Depth               | Does the response provide sufficient explanation, examples, and details? |
| Relevance           | Does the response directly address the requested task?                   |
| Clarity             | Is the response easy to understand and logically structured?             |

Use a **1–5 rating scale** for each criterion, where:

* 1 = Very Poor
* 2 = Poor
* 3 = Average
* 4 = Good
* 5 = Excellent

### Step 5: Prepare a Comparison Table

Create a table containing the results for all scenarios.

Include these columns:

| Scenario | Naïve Prompt | Basic Prompt | Naïve Response Summary | Basic Response Summary | Naïve Score | Basic Score | Key Difference |
| -------- | ------------ | ------------ | ---------------------- | ---------------------- | ----------- | ----------- | -------------- |

Calculate the overall score for each prompt type and identify which prompt type performed better.
 
### Step 6: Analyze the Results

Provide a detailed analysis addressing these questions:

1. Does ChatGPT consistently provide better responses when given basic prompts?
2. How does prompt clarity affect response quality?
3. Does providing additional context improve accuracy?
4. Does a structured prompt produce deeper and more useful answers?
5. Are there scenarios where naïve prompts perform equally well?
6. Which types of tasks benefit most from detailed prompts?
7. Which types of tasks require less prompt structure?
8. What are the major differences between naïve and basic prompts?

### Step 7: Final Findings

Write a summary of the experiment explaining:

* The overall performance of naïve prompts.
* The overall performance of basic prompts.
* The impact of prompt clarity and structure.
* Situations where basic prompts are more effective.
* Situations where naïve prompts may be sufficient.
* Best practices for creating effective prompts.
